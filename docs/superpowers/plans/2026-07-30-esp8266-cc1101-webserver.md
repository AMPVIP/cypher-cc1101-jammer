# ESP8266 CC1101 AP Web Server (v2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a self-hosted WiFi-AP web control panel to `cc1101-tool-esp8266.ino` that drives the full CC1101 command set (including the long-running sweep/RAW commands) while the serial CLI keeps working.

**Architecture:** Reuse the existing `exec()` by routing command output through a redirectable `Print* out`. An `ESP8266WebServer` on port 80 exposes `GET /`, `POST /cmd`, `GET /status`; the browser polls status and issues commands. The blocking sweep commands (`scan`/`rxraw`/`brute`) are refactored into cooperative modes serviced one slice per `loop()` pass via a single `activeMode` enum; `recraw`/`playraw` stay run-to-completion.

**Tech Stack:** Arduino / ESP8266 core 3.1.2, `ESP8266WiFi`, `ESP8266WebServer`, SmartRC-CC1101-Driver-Lib. Verified with `arduino-cli 1.4.1`, FQBN `esp8266:esp8266:d1_mini`.

**Testing note:** No unit-test harness exists (Arduino firmware). Per-task verification = clean `arduino-cli compile` + targeted `grep` checks + a string-literal-preservation diff. Final functional check is an on-device smoke test (the user's).

**Conventions to honor (from prior work):** source stays ASCII + LF; every top-level function has an explicit forward prototype (Arduino's auto-prototype generator mangles this sketch otherwise).

class StringPrint : public Print {

- [ ] **Step 3: Add `serviceActiveMode()` with the scan slice**

Add this function just above `void setup()`:
```cpp
// Advance whichever long-running mode is active by one small slice.
// Called every loop() pass. Keeps the web server responsive.
static void serviceActiveMode(void)
{
    if (activeMode == MODE_SCAN) {
        ELECHOUSE_cc1101.setMHZ(scanCursor);
        int rssi = ELECHOUSE_cc1101.getRssi();
        if (rssi > SCAN_RSSI_MARK && rssi > scanBestRssi) {
            scanBestRssi = rssi; scanBestFreq = scanCursor;
        }
        scanCursor += 0.01;
        if (scanCursor > scanTo) {
            scanCursor = scanFrom;
            if (scanBestRssi > SCAN_RSSI_MARK) {
                long fr = scanBestFreq * 100;
                if (fr == scanCompare) {
                    out->print(F("\r\nSignal found at  "));
                    out->print(F("Freq: "));  out->print(scanBestFreq);
                    out->print(F(" Rssi: ")); out->println(scanBestRssi);
                    scanBestRssi = RSSI_NONE; scanCompare = 0; scanBestFreq = 0;
                } else {
                    scanCompare = scanBestFreq * 100;
                    scanCursor = scanBestFreq - 0.10;
                    scanBestFreq = 0; scanBestRssi = RSSI_NONE;
                }
            }
        }
    }
}
```
